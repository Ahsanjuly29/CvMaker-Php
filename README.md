# 📄 CvMaker - PHP Resume Builder

![PHP](https://img.icons8.com/officel/40/000000/php-logo.png) ![MySQL](https://img.icons8.com/color/48/000000/mysql-logo.png)

CvMaker is a lightweight and efficient PHP-based resume builder developed during my university years to assist students in generating professional CVs effortlessly. It allows users to transform raw data into a polished, recruiter-ready document through an intuitive interface.

## 🚀 Key Features
*   **Automated Generation**: Create professional resumes by inputting personal, educational, and professional data.
*   **Template Variety**: Choose from multiple pre-designed templates to match different industry standards.
*   **Real-time Preview**: View changes in real-time to ensure the layout meets expectations before finalizing.
*   **PDF Export**: High-quality export functionality to save resumes in PDF format for professional use.
*   **Save & Edit**: Persistent storage allows users to save progress and update their CVs at any time[cite: 1].
*   **Secure Authentication**: Integrated user authentication system to ensure data privacy and security[cite: 1].

## 🛠️ Tech Stack
*   **Backend**: Core PHP
*   **Frontend**: HTML5, CSS3, JavaScript, jQuery
*   **Database**: MySQL
